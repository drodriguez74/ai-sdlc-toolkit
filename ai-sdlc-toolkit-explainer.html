§ 05
Quick-Start Lifecycle
⬇
1. Install Globally
$ ./install.sh
Copies toolkit to ~/.copilot/ai-sdlc-toolkit/ and resolves manifest.json with absolute paths. Run doctor.sh to validate.
🔗
2. Link to a Project
$ ~/.copilot/ai-sdlc-toolkit/link-to-project.sh /path/to/repo
Creates symlinks (or copies) from the global toolkit into the project's harness discovery paths. Respects project-level overrides in *-overrides/ folders — those always win.
🎛
3. Tune for the Project
$ ~/.copilot/ai-sdlc-toolkit/tune-project.sh /path/to/repo
Two-phase tuning: first profiles the repo's language, framework, and conventions; then annotates agents and skills with project-specific context so every /command is pre-calibrated.
🧠
4. Onboard — Build the Knowledge Base
/onboard
The orchestrator agent scans the entire codebase and writes .ai-sdlc/project-context.md — a structured knowledge base loaded at the start of every subsequent session.
⚡
5. Use Slash Commands in Your AI CLI
/spec → /plan → /build → /review → /ship
Load project-context.md into your AI session, then invoke commands. Each routes to the right agent persona + skill workflow automatically — no manual context juggling.
§ 06

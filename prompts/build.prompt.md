# /build — Implement a Task

## Goal

Implement one task from the plan in a small, verified slice.

## Instructions

1. Load and follow `skills/using-agent-skills/SKILL.md`.
2. Load the plan and identify the target task.
3. Follow `skills/incremental-implementation/SKILL.md`.
4. For behavior changes, also follow `skills/test-driven-development/SKILL.md`.
5. For framework-dependent behavior, follow `skills/source-driven-development/SKILL.md`.
6. Adopt the appropriate developer agent: `backend-developer`,
   `frontend-developer`, `mobile-developer`, or `data-engineer`.

## Output

Working code, passing tests, evidence of runtime verification, and a small
reviewable diff.

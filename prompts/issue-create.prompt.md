# /issue-create — Create an Issue

## Goal

Open an issue that another engineer could pick up without follow-up questions.

## Instructions

1. Load `skills/using-agent-skills/SKILL.md`.
2. Follow `skills/issue-tracker/SKILL.md`.
3. Title is specific; description has context, expected behavior, and acceptance.
4. Use the active adapter's `create` command.

## Output

Created issue: ID, URL, title, description, acceptance criteria.

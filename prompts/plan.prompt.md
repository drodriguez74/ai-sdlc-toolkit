# /plan — Build an Implementation Plan

## Goal

Translate the spec into ordered, verifiable tasks ready for implementation.

## Instructions

1. Load and follow `skills/using-agent-skills/SKILL.md`.
2. Load the spec produced by `/spec` (or ask which spec to use).
3. Follow `skills/planning-and-task-breakdown/SKILL.md`.
4. Adopt the `tech-lead` agent perspective for technical decomposition.
5. Save the plan to `docs/plans/<name>.md`.

## Output

A plan: ordered tasks with title, behavior delivered, acceptance criteria,
verification, dependencies, and risk.
